# Living World: screenshots

Captured from the running game against the local API (dev sign-in, scratch database), not mocked. Each phase's images are below; before/after pairs share a viewport. Environments are shown as they rendered in a software renderer, so colour and lighting are indicative. No video recordings were made (video output is git-ignored in this repo).
